## 🔍 About Warden-Search

**Warden-Search** is the official lightweight, privacy-focused search engine and start page designed for [Warden Browser](https://github.com). It aggregates instant answers and articles without tracking user queries, profiling, or hidden telemetry.

### ✨ Key Features

* **Multi-Engine Search:** Instant inline results via **Wikipedia API** and **DuckDuckGo Instant Answer API**, plus one-click deep search across **Google**, **Yandex**, **DuckDuckGo**, and **Wikipedia**.
* **URL Query Support (`?q=`):** Built to work seamlessly as the default address-bar search provider (`https://github.io?q=%s`).
* **3 Clean Background Modes:** Switch between interactive **Live Canvas Particles**, **Solid Color**, or **Custom Local Wallpapers** stored locally in your browser without layer overlapping.
* **Quick App Launcher & Themes:** Built-in navigation menu to Warden ecosystem services and automatic Dark/Light theme adaptation.

---

## 🚀 Integration with Warden Browser

To use **Warden-Search** as your default search engine in any desktop browser:

```text
https://github.io?q=%s
```

*(Will be integrated natively as the default search provider in **Warden Browser v0.2-test**).*
